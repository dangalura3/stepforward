# MLBB patch timeline around MPL Indonesia Season 18 (2026) and what each patch changed

Reference date: 7 Nov 2026. "Original Server" = public live release. "Advance Server" = public test server (builds often change before release). Confidence tags: [high] = two or more independent pages agree, [med] = single page or aggregator, [low] = inference or unclear.

## Q1. Which patches were live around MPL ID S18, and which patch (with exact date) went live shortly before the playoffs?

### Takeaway
Four Original Server patches fall in or just before the S18 window: 2.1.95 (4 Aug), 2.1.95a (25 Aug), 2.2.16 (16 Sep, Season 42 launch) and 2.2.16a (14 Oct, hero-only hotfix). The patch live when playoffs started on 4 Nov was almost certainly 2.2.16a (released 14 Oct); I found no later Original Server patch up to 7 Nov. No source I found states which patch version the league itself used, so league adoption dates are an unverified assumption (the live Original patch).

## Q2. Hero, item, emblem and system changes in the patch before playoffs (2.2.16a) and in the previous one (2.2.16)

### Takeaway
2.2.16a (14 Oct) is a six-hero hotfix with no item, emblem or system changes: nerfs to Aulus, Hirara, Eudora and Rafaela, a buff to Kalea, and a Khufra "adjust" with no detail. The earlier finding that it nerfed Rafaela and Aulus is verified. The previous patch 2.2.16 (16 Sep) was a large Season 42 update: Masha and Bruno revamps, 12 buffs, 6 nerfs, 5 adjustments, no item/emblem changes, and economy, turret and targeting changes.

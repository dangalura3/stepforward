Formulas and accuracy checks

Companion page to the StepForward simulator. The measured drafter habits are on the habits page and the code is on the programs page. Every formula the page uses, then every test I ran on it, with the real numbers and what they do and do not prove. Data: MPL ID Season 18 (198 games), MPL PH playoffs (38), MPL MY Season 18 (105), read up to 14 Nov 2026.

1 Formulas2 Accuracy tests3 What it means
In plain words. The simulator guesses what a team will ban or pick, and who wins. To know if a guess method is any good, I hide the answer, let the model guess, then check. I did that thousands of times. The ban guesses are clearly better than luck. The winner guesses are not better than a coin flip yet.

1. Formulas

1.1 Ban model: how likely is a team to ban hero h

Each earlier game i of the team (oldest to newest, n games) gets a weight, then the team's ban frequency is mixed with a league-wide background so small samples do not mislead.

w_i = decay^(n-1-i) × (1 if same side, else sideW) × (h2hW if same opponent, else 1)
        × (phaseW if game is before the patch, else 1) × exp(−λ · days_old)

p_team(h) = ( Σ_i w_i · [h in game i's ban list]  +  k · prior(h) ) / ( Σ_i w_i + k )

prior(h)  = (1 − β) · league_ban_share(h)  +  β · playoff_ban_share(h)      (β = 0.5, playoff switch on)

Position blend:   p(h) = (1 − wp) · p_team(h)  +  wp · p_team,ban#j(h)        (wp = 0.35)
Matchup nudge:    p(h) ← p(h) · exp(μ),  μ = clamp(0.25 · Σ rule strengths, ±1.6)
Lane check:       skip h if opponent's picks + h cannot fill distinct lanes
Finally:          normalise so the list sums to 1

1.2 Pick model

rate(h) = ( team_count(h) + live_count(h) + K · league_pick_rate(h) ) / ( N_games + K ),  K = 10
p(h) = rate(h) + banShift(h)                       (part of a banned hero's chance moves to same player's other heroes and same-lane heroes, strength 0.7)
p(h) ← p(h) · exp(0.30 · Σ combo/counter strengths)  + small direct counter bonus
p(h) ← p(h) · (1 + 0.5 · early · min(1, opp_rate/0.5))    (denial: taking what the other team needs)
p(h) ← p(h) · 0.05 if the hero cannot fit any free lane

1.3 Win model (Draft verdict) and series odds

z = temp · ( team + hero + comp + style + side )         temp = 0.4,  P(win) = clamp( 1/(1+e^−z), 0.35, 0.65 )
team  = 0.8 · ( logit(team record) difference )
hero  = 6.0 · ( hero evidence difference )
comp  = 0.02 · ( composition rating difference )     style = 0.12 · ( style rating difference )     side = 0.3 for blue

Series (Bayesian Bradley-Terry):  P(a beats b) = 1 / (1 + exp(−(θ_a − θ_b + β_blue·side)))
θ ~ Normal(0, τ=1), blue-side bonus β_blue, sampled by random-walk Metropolis (36,000 steps, burn 8,000, thin 10);
teams with no games get fresh draws from the prior (very wide range).

1.4 Python engine (CatBoost / NumPy / SciPy package)

z_i = w0 + Σ_j w_j · x_ij                    ŷ_i = σ(z_i) = 1 / (1 + e^−z_i)
L(w) = −(1/N) Σ_i [ y_i·log ŷ_i + (1 − y_i)·log(1 − ŷ_i) ]  +  (l2/2) · ||w||²
∂L/∂w_j = Σ_i ( σ(z_i) − y_i ) · x_ij  (+ l2 · w_j)          solved with L-BFGS (SciPy)
patch weight: w_patch(t) = e^(−λ t)      features: 2N-dim multi-hot of heroes, smoothed target encoding,
synergy and counter matrices (leave-one-out), role-balance indices
best pick:  ΔP_k = P(win | draft + hero k) − P(win | draft), top 3 reported

The CatBoost backend is wired in but I could not train or test it here (no package installs). The logistic backend has 22 passing unit tests.

1.5 Drafter-habit hooks (new)

repeat push (OFF):   p(h) ← p(h) · exp(w)   for heroes this team banned last game of the same series; w = 0 in the app
hot hero (OFF by default, you set it):
   own pick:      p(h) ← p(h) · exp(s)          for each hot hero h of the team,  s = chase strength 0 to 0.9
   opponent ban:  p(h) ← p(h) · exp(0.6 · s)    ban the other team's hot hero

1.6 How accuracy is measured

  • Walk-forward: each game is predicted using only games played before it.
  • hit@k: share of real bans found in the model's top k (random is about k%, since there are about 100 heroes).
  • log-score: average of ln(probability given to the real hero). Higher (closer to 0) is better; guessing evenly over 100 heroes scores −4.6.
  • Log-loss and Brier (winner guesses): lower is better; a coin flip scores 0.693 log-loss.
  • 95% range: bootstrap, resampling series.

3. What this means

  • Ban guesses are real: about 1 in 4 first guesses and 1 in 2 within five picks, against about 1% and 5% for luck.
  • Playoff drafts differ from the regular season, and using them helps a little. Malaysia's playoffs add a small further gain.
  • Winner guesses are not better than a coin flip with the data I have. Treat the verdict and Best-3 gains as hints.
  • Regional gaps: Türkiye, CIS and Myanmar have results but no readable draft lists, so those teams start from the league average with a wide range.
  • Drafter habits: teams do repeat bans, but that is already modelled; "hot hand" is a story I could not test.
